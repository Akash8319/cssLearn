🚀 Learning Roadmap

1. The Fundamentals
   Selectors & Specificity: Understanding how the browser decides which styles win.

   he Box Model: Mastering margin, border, padding, and content.

   Typography: Working with web fonts, line heights, and spacing.

   Colors: Hex, RGB, HSL, and transparency.

2. Layout & Positioning
   Display Property: Block, inline, and inline-block.

   Flexbox: Building one-dimensional layouts with ease.

   CSS Grid: Mastering two-dimensional layouts for complex designs.

   Positioning: Static, relative, absolute, fixed, and sticky.

3. Advanced Concepts
   Responsive Design: Using Media Queries to make sites look great on mobile.

   Variables (Custom Properties): Keeping code DRY (Don't Repeat Yourself).

   Animations & Transitions: Adding life to the UI with keyframe animations.

   Preprocessors: Introduction to Sass/SCSS.
